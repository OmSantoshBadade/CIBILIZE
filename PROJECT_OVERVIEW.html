Project Overview

Cibilize

A personal-finance web app focused on Indian credit behavior. It helps users explore credit cards, estimate credit health, track spending, run common money calculators, and chat with an AI assistant — all in one place.

React + TypeScript Node.js / Express PostgreSQL Google Sign-in Gemini AI

Big-picture architecture

The product splits into two main pieces that work together: a web app users interact with, and a backend API that handles data, login, and AI calls.

Feature highlights

Credit card recommendations

Users browse a curated card catalog from the database. Personalized suggestions combine preferences (spending style, income band, desired benefits, fee limits) with matching rules so suggestions fit the profile. An AI-enhanced flow can also recommend cards from a fixed, approved list alongside a broader financial snapshot.

AI Agent

A chat-style assistant available after sign-in. It answers in natural language with streaming replies, and can use context from the user’s recent recommendation results so answers feel relevant rather than generic.

CIBIL score tracker

Users enter simple facts — income, loans, utilization, missed payments, age — and the system returns an estimated score band, risk view, improvement ideas, loan eligibility hints, and next-step milestones.

Note for presenters: this is a decision-support and learning tool, not an official CIBIL report. Real scores come only from authorized credit bureaus.

Expense tracker

Add expenses manually and see lists plus summary stats. Optional file uploads for receipts or statements are stored via a cloud media service and feed into server-side processing workflows.

Security & quality

  • HTTPS-minded setup with rate limiting and security headers on the API.
  • Input sanitization on all incoming requests.
  • Authentication required for core tools so personal data stays behind login.
Cibilize bundles credit education, card discovery, spending visibility, and calculators in one place — and layers AI where it helps explain and recommend, while keeping structured data and rules as the backbone.
